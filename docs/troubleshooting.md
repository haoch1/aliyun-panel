# 故障排查

## 域名解析失败与网络超时

`ENOTFOUND`、`EAI_AGAIN` 表示服务进程无法解析接口域名，增加 RAM 权限不能解决

1. 在面板实际部署主机或容器中检查 DNS 与网络，而不是只检查浏览器
2. 检查 ECS 地域端点、国际站费用端点与 Telegram 地址是否可达
3. 检查 VPN、系统代理、DNS、防火墙及容器网络，避免把宿主机回环代理地址直接填入容器
4. 网络恢复后等待冷却结束，或在需要时重新加载页面；实例检测和账单查询可分别使用“立即检测”和“同步账单”

读取失败保留已有成功数据并标记缓存；缓存不代表本次查询成功。每日图表瞬时网络错误冷却一分钟，其他错误冷却五分钟，冷却不会自行轮询图表接口

## 账号所属站点不匹配

| 账号                      | BSS 端点                               |
| ------------------------- | -------------------------------------- |
| 国内站 `aliyun.com`       | `business.aliyuncs.com`                |
| 国际站 `alibabacloud.com` | `business.ap-southeast-1.aliyuncs.com` |

修改实例所属凭据的站点配置后重新查询账单；实例地域不会自动决定账号站点。面板不会遍历不同站点尝试凭据

## 权限不足

依据日志中的 API 名称补充权限，参考 [RAM 权限说明](ram-permissions.md)

独立 EIP 图表调用 `vpc:DescribeEipMonitorData`，不是 ECS 权限；仅有 `AliyunECSFullAccess` 不代表已具备该读取权限。无权限或监控缺失时，不回退为零流量

新 EIP 检测后会按分钟采集，界面显示“等待流量采样”表示云端还没有返回当前绑定时段的有效记录。历史 EIP 的已保存流量仍累计到原实例；出现查询失败时检查日志中的 `traffic-query`，不要通过清空数据库解决。分钟和小时采样会去重，不需要人为删除旧 EIP 历史

稳定 EIP 的流量数据每五分钟批量更新，分钟精度保持不变，实际显示还受云端数据延迟影响；反复刷新页面不会强制增加采集请求。新 EIP 仍立即查询，前十分钟没有有效采样时最快每分钟探测一次。状态检测与账号共享流量保护继续使用设置中的检测间隔

换 IP 后若出现 `InvalidIpInstanceId.NotFound`，先区分报错属于当前 EIP 还是旧绑定。已确认换绑、旧监控记录不存在时，面板保留历史累计并停止旧来源补采，未采集部分无法补回，只记录一次警告日志，不在当前流量页面持续显示；这不表示新 EIP 或账号 CDT 用量失败。当前 EIP 的同类 404 仍会报错和重试，不能直接忽略。日志详情包含来源与绑定编号，便于追溯

检查是否存在显式拒绝、资源 ARN 地域或账号不符，以及用户组、角色继承权限。不要仅根据策略名称判断实际有效权限

## 设置十五分钟后仍看到请求

检测间隔限制常规 ECS 和共享流量检测，不限制定时边界、月初、动作结果核实、手动检测及独立账单查询

操作审计页面自身的 `LookupEvents`、`ListEventNames`、`DescribeTrails` 等请求也会产生记录，不能计入面板轮询次数。本面板未调用操作审计或 RAM 管理 API

筛选实际 RAM 用户、AccessKey、地域、服务与 API 名称后比较时间。浏览器主账号登录产生的 root 记录，不代表保存的 RAM AccessKey 请求已变为主账号调用

## AccessKey 异常调用提醒

结合邮件中的时间、来源 IP 与 API 名称，对照部署主机出口和面板日志判断。提醒本身不能证明凭证泄露，也不能直接判定属于正常调用

若来源或操作不符合预期，应在 RAM 停用相应 AccessKey、核查操作审计并重新配置凭据。不要在 Issue、截图或公开日志中发布 Secret、Token、会话 Cookie 或完整请求签名

## 余额为零或账单不同步

账号余额与实例税前费用是不同字段。接口成功返回零余额时按零展示；查询失败时显示异常或缓存，不能直接当作零余额

账单按所选月份及实例 ID 匹配，存在统计延迟；共享余额不能按实例逐行相加，最终结算以阿里云账单为准

## Telegram 未收到通知

依次检查总开关、Token 与 Chat ID、机器人是否已接收 `/start`、对应类型是否勾选，以及通知队列日志

预览不发送消息。每日汇总依赖时间与时区；每轮汇总默认关闭。代理必须由服务进程或容器可达，网络失败和限流可能延迟投递，最多尝试五次

## 登录与数据

- 反向代理后出现来源校验失败：核对 `PUBLIC_ORIGIN` 与浏览器地址的协议、域名和端口
- HTTPS 登录后 HTTP 页面无法保持会话：Secure Cookie 仅用于 HTTPS，统一使用配置的对外 Origin
- 更换目录后要求初始化：检查挂载卷、`DATA_DIR` 和文件权限，不要覆盖原始数据
- 已有凭据无法解密：恢复配套 `encryption.key` 或原始环境变量密钥，不能仅恢复数据库
- 健康检查成功但云端报错：健康接口仅检查 HTTP 服务，仍需核对权限、网络与各模块日志

提交问题时提供脱敏错误码、API 名称、版本或提交号、部署方式及复现步骤；不要附带数据目录或真实凭据
