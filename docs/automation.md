# 自动化与调度

## 决策优先级

每轮检测读取指定实例的 ECS 状态及相应账号的共享流量，再按规则判断；动作提交与动作完成分别记录，只有核实目标状态后才记录完成

| 条件                                                       | 行为                                 |
| ---------------------------------------------------------- | ------------------------------------ |
| 云端锁定、到期、不可用、状态读取失败                       | 阻止自动操作，记录原因               |
| 任务执行中或 Starting / Stopping 等过渡状态                | 不重复提交动作                       |
| 流量保护已触发，恢复条件未满足                             | 保持停止；若外部启动则再次请求停止   |
| 达到阈值且配置为关机                                       | 停止运行中的实例，并保持流量保护限制 |
| 达到阈值且配置为仅告警                                     | 保持当前运行状态，但阻止自动启动     |
| 处于计划停机时段                                           | 停止运行中的实例，保活不启动         |
| 人工停机限制生效                                           | 不自动启动                           |
| 启用了流量保护，但本月流量无效、过期或读取失败             | 不自动启动                           |
| 停止状态、流量条件有效、计划允许且保活开启或定时启动待执行 | 提交启动并核实状态                   |
| 已运行且无停止条件                                         | 保持运行                             |

关闭流量保护时，启动决策不要求共享流量查询有效；开启保护后，启动必须使用当前月份且五分钟内的有效流量快照，不能沿用上月数据

## 保活

保活是周期性状态检测与重启机制，使用 ECS `StartInstance`；与普通停机的资源保留方式不同

保活无法即时获知云端状态变化。实例因库存、抢占式回收等原因停止时，需等待下一次检测发现停止后尝试启动；实际成功取决于实例是否仍存在、云端库存、配额、余额和权限。释放后的实例不能通过保活恢复

人工停机、计划停机和流量保护期间，保活开关可以保持开启，但自动启动受到上述条件约束

## 移除监控

实例操作菜单中的“移除监控”删除面板内对应实例的接入记录与自动化规则，后续不再对该实例执行检测、保活、流量保护或定时开关机。此操作不调用云端停止或释放接口，实例状态和计费保持原有规则。

同一接入配置仍有其他实例时保留凭证；移除最后一台实例时删除该配置保存的凭证。已有实例操作尚未完成时，面板阻止移除，需先核对操作结果。重新接入已移除的实例时，应重新配置自动化规则。

## 流量关机与恢复

默认阈值为共享额度的 90%，支持百分比或绝对流量阈值，默认动作为“关机并通知”

同一账号的中国内地与非中国内地流量池分别处理，账号下未接入面板的其他云产品仍可能消耗额度。官方统计存在延迟，阈值应预留余量

“流量恢复后自动开机”默认关闭。开启后，在新有效用量低于阈值时解除流量保护限制，再依据保活、定时及人工停机条件决定是否启动；月初重置也遵循这一流程，不保证在 00:00 精确开机

仅通知模式不会因超限主动停止运行中的实例，但会阻止保活和定时自动启动。持续超限不重复产生同类阈值提醒，恢复后再次超限可重新提醒

## 定时开关机

默认时间 08:00–23:00，时区 `Asia/Shanghai`，可配置跨午夜运行时段。每日计划默认关闭，启用后服务按当前时间计算应运行或停止的时段

运行时段开始时，自动启动仍受流量保护与人工停机限制；停机时段内，即使保活开启也不启动。仅配置定时开机时，不设置计划停止时段

调度器每分钟检查时段边界，跨时段或服务恢复后可补偿执行；不会因为检测间隔设置为十五分钟而等待整轮间隔后才判断计划。夏令时跳过与重复的本地时间使用时区规则处理

## 停机模式与费用

所有停止请求显式传入停机模式，使用 `ForceStop=false`

| 模式                          | 行为与计费                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| `KeepCharging` 普通停机，默认 | 保留计算资源，继续按照实例实际计费规则收费                                                 |
| `StopCharging` 节省停机，可选 | 符合条件时释放计算资源，重新启动可能受库存限制；磁盘等资源仍可能计费，固定公网 IP 可能变化 |

独立 EIP 有自身的保留和计费规则，不因 ECS 普通停止而自动释放。启动、停止及资源保留的结果以阿里云 API 和对应实例类型规则为准

参考：[StopInstance](https://www.alibabacloud.com/help/en/ecs/developer-reference/api-ecs-2014-05-26-stopinstance)、[节省停机模式](https://www.alibabacloud.com/help/en/ecs/user-guide/economical-mode)

## 查询频率

未接入实例或已移除全部实例时，后台跳过自动检测、账单查询、检测日志和汇总通知；已配置实例但首次发现失败时，仍按检测间隔重试，不将查询失败视为已移除实例

| 任务                    | 调度行为                                                     |
| ----------------------- | ------------------------------------------------------------ |
| 常规 ECS / 共享流量检查 | 按设置的检测间隔，默认 60 秒                                 |
| 定时边界与月初          | 每分钟检查是否需要额外运行一轮，未到边界不因此查询云端       |
| 手动“立即检测”          | 主动执行一轮查询与规则判断                                   |
| 已提交动作结果          | 独立核实状态，可能短时间多次读取                             |
| 账单与余额              | 默认成功缓存 3600 秒；失败按不超过十五分钟的间隔重试         |
| 每日监控图表            | 查看时按需查询，五分钟内复用缓存；后续补最近两小时与新增时段 |
| 任务队列与通知          | 每五秒处理本地队列，不等同于每五秒查询阿里云                 |

同轮查询按账号与地域分组，ECS 状态、公网 IP 和 EIP 绑定复用同一响应，共享流量同账号同轮复用。网络类只读失败最多尝试三次，开关机写请求不由 SDK 自动重放；权限错误进入冷却，待后续检测重试

设置检测间隔并不限制所有 API 的总请求次数。排查频率时应按具体 API、RAM 用户、实例地域及时间比较，而不是仅根据操作审计列表总行数判断
