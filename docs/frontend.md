# 前端维护说明

## 组件与样式

前端使用 React 与 TypeScript。通用组件位于 `src/components/ui`，页面组件复用统一的标题、按钮、卡片、表格、分段选择、分页与提示组件。

与 LightSail Panel 共用同一份组件约定：弹窗和移动导航使用 Radix Dialog，普通选择使用 Radix Select，可搜索选择使用 Radix Popover + cmdk，操作菜单使用 Radix Dropdown Menu，时间选择使用 Radix Popover，分段控件及提示使用 Radix Toggle Group / Tooltip。定位、边缘避让、嵌套焦点、Esc 和滚动锁定由这些组件处理，不再为每个页面另写一套。

`tokens.css`、`foundation.css`、`controls.css` 以及 `Modal`、`Sidebar`、`Select`、`ActionMenu`、`TimePicker`、`SegmentedControl`、`Tooltip` 在两个独立仓库中保持内容一致。修改公共规范时应同步这两处，不引入对另一个仓库本地路径的运行依赖。

字体使用统一字号与字重变量；控件以 40 px、紧凑操作以 34 px 为基准，触屏主要操作至少 44 px。过渡使用 120 / 150 / 180 ms 三档变量。移动端搜索输入为 16 px，避免 iOS 聚焦放大，并为刘海和底部手势区保留安全间距。

| 样式文件         | 职责                                   |
| ---------------- | -------------------------------------- |
| `tokens.css`     | 主题颜色、字体与尺寸变量               |
| `foundation.css` | 基础元素、字体、表单与焦点样式         |
| `controls.css`   | 按钮、下拉菜单、时间选择器、弹窗及分页 |
| `layout.css`     | 导航、页面结构、表格与卡片基础布局     |
| `views.css`      | 实例、账单、日志、设置与实例发现布局   |
| `traffic.css`    | 流量汇总、图表与每日明细               |
| `loading.css`    | 数据区域占位与加载过渡                 |
| `inventory.css`  | 两面板共用的实例列表与流量优先卡片     |

新增页面应复用上述组件和主题变量，避免以额外样式文件反复覆盖同一选择器。

## 表格布局

表格首列与左侧内边距对齐，末列与右侧内边距对齐，单元格垂直居中。末列按内容需要预留紧凑宽度，其余空间分配给中间各列；同列的表头与数据使用一致的对齐规则。数字采用等宽数字特性，实例概况中的标签与计数使用相同字号和行高。

- 实例表按名称、状态、IP、流量和操作控件的实际内容分配列宽，限制流量进度条长度，并保留操作列左侧分隔线。
- 账单表、每日流量明细和检测日志明细为末列设置紧凑宽度，前面的数据列均匀分配剩余空间，避免最后一列内部出现整块空白。
- 通知记录和实例发现结果根据时间、名称、地域、状态等内容分配明确的列宽。
- 初次加载时复用对应表格的列宽与基础布局；刷新期间保留已成功读取的数据。

页面宽度不超过 900 像素时使用抽屉导航，实例列表由 `InventoryTable` 切换为 shadcn/ui Card（radix-vega）的 `size="sm"` 组合，直接复用已安装的标准 Card 源码。`CardHeader` 展示名称、地域、状态和选择，`CardContent` 中流量占满宽度，以 14 px 数值、额度、进度和明细入口优先展示；IP 独占一行，费用、保活、流量保护与计划按双列分组，`CardFooter` 放置操作。桌面表格与手机卡片复用同一份数据、选中状态和操作处理，不再通过把表格元素强制改为网格来模拟卡片。

`shadcn.css` 仅加载 Tailwind 主题与工具类，不引入 Preflight，标准 Card 组件使用面板已有颜色和字号变量。来源见 [shadcn/ui Card](https://ui.shadcn.com/docs/components/radix/card)。全选置于筛选栏。不超过 600 像素时，账单、日志检测明细、通知记录和实例发现结果转为卡片或字段分组。每日流量明细保留四列表格。较宽表格的滚动限定在自身容器内。

## 交互与可访问性

- 实例列表同时支持文本搜索和状态筛选，并提供清除筛选操作。部分选中时，全选框显示中间状态。
- 实例、地域及时区选择器支持搜索、无匹配结果提示、方向键导航、Enter 选择、Esc 关闭和焦点返回；中文输入法组合输入期间不触发选择。
- 统计范围与日志类型使用单选分段控件，支持键盘方向键切换焦点。
- 日志每页条数支持 20、50、100 条，并保存在当前浏览器中；分页控件显示当前页及相邻页。
- 弹窗限制内部滚动、管理焦点，并支持 Esc 关闭；下拉菜单与图表提示根据可用空间避让边缘。
- 普通数据输入框保留密码管理器忽略标记，密码字段保留密码输入行为。
- 主题颜色通过变量切换；减少动态效果的系统偏好将关闭过渡与动画。

## 本地验证

```sh
pnpm check
pnpm build
pnpm test
```

使用 `/?demo=1` 检查演示数据与交互，可避免连接真实云端和发送通知。界面验证至少覆盖实例、流量、账单、日志、设置和实例发现弹窗，包含桌面、平板与手机宽度，以及浅色、深色和加载状态。

演示模式的检查结果不能替代真实环境中的 API 权限、资源状态及通知投递验证。
