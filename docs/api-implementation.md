# API 与查询机制

## 接口用途

| 功能                 | 接口                                                     | 处理方式                                                       |
| -------------------- | -------------------------------------------------------- | -------------------------------------------------------------- |
| 状态与保活判断       | `DescribeInstances`                                      | 按账号、地域分组查询，同一响应更新状态与公网绑定               |
| 流量保护及额度       | `ListCdtInternetTraffic`                                 | 查询账号共享流量池，同轮复用账号缓存，内地与非内地额度分别处理 |
| 实例月流量及每日流量 | `DescribeEipMonitorData` / `DescribeInstanceMonitorData` | 按公网绑定类型查询监控数据，历史持久化，后续增量查询           |
| 开关机               | `StartInstance` / `StopInstance`                         | 提交后独立查询结果，确认实例完成动作后再更新任务结果           |

## 查询与调度设计

- 常规实例查询遵循检测间隔，不设置独立的固定五分钟发现任务
- 后台查询的同一个 `DescribeInstances` 响应同时更新状态、公网 IP 与 EIP 标识，无需另起发现请求
- 点击“立即检测”检查规则时复用同轮状态响应
- 保留定时边界、月初流量恢复和在途任务结果核实，不因设置较长检测间隔而延迟这些动作
- 网络类只读失败最多尝试 3 次；权限拒绝不重试；开关机写请求不由 SDK 自动重放
- 每日流量查询失败保留成功历史；瞬时网络错误冷却 1 分钟，其他错误冷却 5 分钟；冷却本身不会定时发出监控请求

## 每日流量口径

实例列表的本月流量与流量详情均来自同一实例的公网监控数据，按绑定时间段合并该实例使用过的 EIP。先累计整个范围的入站和出站字节，再取两者较大值作为单向流量，不累加每日或各 EIP 的较大值；详情的合计为入站与出站之和。流量保护弹窗与关机判断继续使用账号共享流量池，避免将单台实例监控用量误用于账号额度保护

`traffic_bindings` 保存账号、实例、监控来源和绑定起止；同一 EIP 转绑或切回时创建新的时间段，历史不会因当前来源变化被隐藏。相同云账号下不同 RAM 凭证也按 EIP 的归属分段。边界采用检测时刻所在分钟，不能保证还原两次检测之间未经观察的绑定变化

`traffic_samples` 以绑定记录、时间戳和采样周期为唯一键，重查执行覆盖写入。读取时只接受绑定时段内的完整采样；同一小时存在完整小时数据时不再累加分钟数据，写入完整小时后删除其覆盖的完整分钟明细。绑定边界和当前小时保留分钟记录，较早的整点数据使用小时记录，避免长期存放全部分钟序列

后台复用现有实例检测结果记录绑定，在自动化决策完成后异步采集 EIP，采集失败不阻塞开关机任务。没有独立的实例发现计时器。稳定绑定的分钟序列每五分钟批量读取，查询结束时间随页面刷新前移也不会绕过节流；后台、页面及重启后的进程共用持久化查询状态。新 EIP 立即启动采集，前十分钟尚无有效入出采样时按检测轮次探测，最快一分钟一次，首个有效采样后切换为五分钟批量读取

完整小时结束五分钟后才请求小时序列，完整结果随后直接复用，仅在新小时形成或历史有缺口时继续查询；已缓存历史无需整月重拉。EIP 解绑会立即补查原绑定尾部，不受稳定绑定的五分钟节流影响。已结束且齐全的绑定不再轮询，旧绑定缺口和连续失败逐步退避至最多一小时重试一次，恢复后继续补齐

EIP 的分钟请求按每次最多 200 点拆分，入站与出站共用云端响应，使用 UTC 秒级时间。两台稳定 EIP、每分钟检测并持续读取本月数据的回归模拟中，流量 RPC 从每小时 144 次降至 26 次（24 次分钟批量、2 次小时归档）；首次回填、新绑定探测、未缓存日期范围与失败补采可能增加调用。接口仍可能有采样延迟，新绑定尚无采样时显示“等待流量采样”

列表和详情订阅同一实例累计结果，后台成功保存新采样后刷新前端缓存。更换 EIP 不清空实例历史，近 7 天、近 30 天和本月均按同一绑定台账筛选。失败保留已成功采集的旧 EIP 和当前 EIP 数据；当前绑定网络失败冷却一分钟、其他失败冷却五分钟，已结束绑定连续失败逐步延长冷却至一小时，同一绑定的小时与分钟请求共享失败冷却

当已结束的 EIP 绑定返回 `InvalidIpInstanceId.NotFound`、`InvalidAllocationId.NotFound` 或 `InvalidInstanceId.NotFound`，且元数据已确认当前来源不同，将其保存为 `traffic-binding-unavailable` 终止状态，保留采样并停止请求。升级前缓存中的同类 404 也会在冷却结束前直接转换，记录一次警告日志及原绑定来源，不清空或伪造缺失流量。当前绑定的 404 不适用这一规则，继续作为失败处理

流量接口的 `errors` 只表示当前来源查询失败，`warnings` 只表示仍可重试的旧绑定历史补采失败。已终止补采的旧 EIP 缺口仅保留一次警告日志，不随每次查询返回页面提示，升级前已保存的终止记录也适用。旧来源的网络、权限错误仍按退避策略补采；当前来源即使同时失败也不会被隐藏

升级只迁移旧版已经保存且具有明确实例与来源的字节记录。旧版曾对多个来源查询同一整月，产生的重叠按已有记录的时间顺序切分，不能简单求和；这类迁移数据的绑定边界属于估计。没有记录的历史绑定时刻、离线期间快速更换的 EIP，以及未被保存的旧 EIP 尾部数据不能保证完整恢复，不为未知时段回填其他实例可能产生的流量

## 审计记录

实例状态查询等 API 调用可能出现在阿里云操作审计中，包括只读查询

核对实际轮询频率时，应在实例所在地域按 ECS 服务、事件名、时间及该 RAM 用户/AccessKey 筛选。`LookupEvents`、`ListEventNames` 属于操作审计查询接口，本面板没有调用这些接口
